# Linear Regression: A Summary

### 1. Beyond Simple Parameter Estimation
This document moves beyond estimating parameters of univariate distributions to more complex tasks like:
* Parameters of multivariate distributions (e.g., multivariate Gaussians).
* More complex functionals.
* Estimating discrete conditional distributions, known as **pattern recognition** or **pattern classification**.
* Estimating continuous conditional distributions, known as **regression**.

---
### 2. Prediction Problems and Supervised Learning
Many real-world problems are **prediction problems**, characterized by:
1.  An **outcome measurement** (output), which can be quantitative (e.g., stock price) or categorical (e.g., heart attack/no heart attack).
2.  A set of **features** or **inputs** (quantitative or categorical) used to predict the output.
The core assumption is that input variables explain some of the output's variability. A set of input/output data, called a **training set**, is used to build a **prediction model** (learner) to predict outcomes for new, unseen objects.

This process is termed **supervised learning** because the outcome variable guides the learning process, akin to a teacher providing correct answers for each input.

---
### 3. Regression vs. Classification
Based on the output type, prediction tasks are divided into:
* **Regression**: Deals with quantitative outputs (e.g., real or integer numbers).
* **Classification** (or pattern recognition): Deals with qualitative or categorical outputs from a finite set of classes without explicit ordering (e.g., spam/not spam). Qualitative variables are also called factors.

---
### 4. The Simple Linear Model
The simplest regression model is the linear model:
$y = \beta_0 + \beta_1 x + w$
Where:
* $x \in \mathbb{R}$ is the regressor (independent variable).
* $y \in \mathbb{R}$ is the measured response (dependent variable).
* $\beta_0$ is the intercept.
* $\beta_1$ is the slope.
* $w$ is the model error with $E[w] = 0$.

This implies:
* The conditional expectation of $y$ given $x$ is $E[y|x] = f(x) = \beta_0 + \beta_1 x$. This $f(x)$ is known as the **regression function**.
* The conditional variance of $y$ given $x$ is $Var[y|x] = Var[w]$.

---
### 5. What "Linear" Means in Linear Models
A model is "linear" if the input/output relationship is **linear in the model parameters**, not necessarily in the dependent variables. This means:
1.  The response $y$ is described by a linear combination of parameters (slopes, intercept).
2.  No parameter appears as an exponent or is multiplied/divided by another parameter.

Examples:
* $y = \beta_0 + \beta_1 x$ is linear.
* $y = \beta_0 + \beta_1 x^2$ is linear (by setting $X = x^2$, it becomes $y = \beta_0 + \beta_1 X$).
* $y = \sum_{m=1}^{M}\beta_{m}\phi_{m}(x)$ is linear, where $\phi_m(\cdot)$ are basis functions.
* $y = B_0 x^{\beta_1}$ can be linearized to $\log(y) = \log(B_0) + \beta_1 \log(x)$, or $Y = \beta'_0 + \beta_1 X$.
* $y = \beta_0 + \beta_1 \beta_2^x$ cannot be linearized.

---
### 6. Model Estimation for Simple Linear Regression
Given $N$ i.i.d. pairs of observations $D_N = \{\langle x_i, y_i \rangle\}$, $i=1,...,N$, generated by $y_i = \beta_0 + \beta_1 x_i + w_i$.
Assumptions:
1.  $w_i$ are i.i.d. realizations of a random variable $w$ with $E[w]=0$ and constant variance $\sigma_w^2$ (**homoscedasticity**).
2.  $x_i$ are non-random and observed with negligible error.
The unknown parameters $\beta_0$ and $\beta_1$ (regression coefficients) can be estimated using the **least-squares method**.

---
### 7. Least Squares Formulation (Simple Linear Regression)
The method aims to find estimates $\hat{\beta}_0, \hat{\beta}_1$ and fitted values $\hat{y}_i = \hat{\beta}_0 + \hat{\beta}_1 x_i$ such that the **Residual Sum of Squares (SSE)** is minimized:
$SSE_{emp}(b_0, b_1) = \sum_{i=1}^{N}(y_i - b_0 - b_1 x_i)^2$.
The **Ordinary Least-Squares (OLS) solution** is found by minimizing this quadratic error function:
$\{\hat{\beta}_0, \hat{\beta}_1\} = \text{arg min}_{\{b_0, b_1\}} SSE_{emp}(b_0, b_1)$.
The **empirical risk** or **training error** is defined as:
$\hat{MISE}_{emp} = \text{min}_{\{b_0, b_1\}} \frac{SSE_{emp}(b_0, b_1)}{N} = \frac{SSE_{emp}(\hat{\beta}_0, \hat{\beta}_1)}{N}$.
$SSE_{emp}$ is a function of the training set and thus a realization of a random variable.

---
### 8. Multiple Linear Regression
This extends the linear model to multiple input variables: $x \in \mathcal{X} \subset \mathbb{R}^n$ and a dependent variable $y \in \mathcal{Y} \subset \mathbb{R}$.
The model is: $y = \beta_0 + \beta_1 x_{\cdot 1} + \beta_2 x_{\cdot 2} + \dots + \beta_n x_{\cdot n} + w$.
Here, $w$ is a random variable with mean zero and constant variance $\sigma_w^2$.
In matrix notation: $y = x^T \beta + w$.
* $x = [1, x_{\cdot 1}, x_{\cdot 2}, \dots, x_{\cdot n}]^T$ is a $[p \times 1]$ vector (where $p=n+1$ is the total number of parameters).
* $\beta = [\beta_0, \dots, \beta_n]^T$ is the vector of parameters.

For $N$ observations $D_N = \{\langle x_i, y_i \rangle: i=1,...,N\}$, where $x_i = (1, x_{i1}, ..., x_{in})$, the model can be written as:
$Y = X\beta + W$.
Where:
* $Y$ is the $[N \times 1]$ response vector.
* $X$ is the $[N \times p]$ data matrix (design matrix).
* $\beta$ is the $[p \times 1]$ vector of parameters.
* $W$ is the $[N \times 1]$ vector of errors $w_i$, assumed uncorrelated, with mean zero and constant variance $\sigma_w^2$ (homogeneous variance). So, $Var[W] = \sigma_w^2 I_N$.

---
### 9. The Least-Squares Solution (Multiple Linear Regression)
The least-squares estimator $\hat{\beta}$ minimizes the sum of squared residuals:
$\hat{\beta} = \text{arg min}_b \sum_{i=1}^{N}(y_i - x_i^T b)^2 = \text{arg min}_b ((Y - Xb)^T (Y - Xb))$.
Taking the derivative with respect to $b$ and setting it to zero yields the **normal equations**:
$(X^T X)\hat{\beta} = X^T Y$.
Assuming $X$ is of full column rank (so $X^T X$ is invertible and positive definite), the solution is:
$\hat{\beta} = (X^T X)^{-1} X^T Y$.

---
### 10. Empirical Risk (Multiple Linear Regression)
The residual sum of squares for the fitted model is $SSE_{emp} = ((Y - X\hat{\beta})^T (Y - X\hat{\beta})) = e^T e$, where $e$ is the vector of residuals.
The empirical risk or training error is $\hat{MISE}_{emp} = \frac{SSE_{emp}}{N}$.

---
### 11. Analysis of the Least Squares (LS) Estimate
If the linear dependency assumption holds and $E[w]=0$, then $\hat{\beta}$ is an unbiased estimator of $\beta$.
An unbiased estimator of the error variance $\sigma_w^2$ is the residual mean square:
$\hat{\sigma}_w^2 = \frac{(Y - X\hat{\beta})^T (Y - X\hat{\beta})}{N-p} = \frac{SSE_{emp}}{N-p}$.
If the errors $w_i$ are uncorrelated and have common variance $\sigma_w^2$, the variance-covariance matrix of $\hat{\beta}$ is:
$Var[\hat{\beta}] = \sigma_w^2 (X^T X)^{-1}$.

---
### 12. Variance of the Prediction
For a generic input value $x = x_0$:
* The prediction $\hat{y}(x_0) = x_0^T \hat{\beta}$ is unbiased: $E[\hat{y}(x_0)] = x_0^T \beta$.
* The variance of the prediction is $Var[\hat{y}(x_0)] = \sigma_w^2 x_0^T (X^T X)^{-1} x_0$.
Assuming normal residuals $w$, a $100(1-\alpha)\%$ confidence interval for the true regression value $E[y|x=x_0]$ is:
$\hat{y}(x_0) \pm t_{\alpha/2, N-p} \hat{\sigma}_w \sqrt{x_0^T (X^T X)^{-1} x_0}$.
Where $t_{\alpha/2, N-p}$ is from the t-distribution with $N-p$ degrees of freedom.

---
### 13. Generalization Error of the Linear Model
The linear predictor $\hat{y} = x^T \hat{\beta}$ is estimated using the training set $D_N$. $\hat{\beta}$ is a random variable. We want to predict a future output $y(x)$ for a test input $x$, where $y(x)$ is independent of $D_N$.
The Mean Squared Error (MSE) for a test input $x$ is:
$MSE(x) = E_{D_N, y}[(y(x) - x^T \hat{\beta})^2] = \sigma_w^2 + E_{D_N}[(x^T \beta - x^T \hat{\beta})^2]$.
The integrated version is $MISE = \int_x MSE(x)p(x)dx$.

---
### 14. Expected Empirical Error vs. MISE (Generalization Error)
The empirical risk (training error) is generally an optimistic (biased) estimate of the true generalization error (MISE).
The expectation of the empirical mean squared error is:
$E_{D_N}[\hat{MISE}_{emp}] = E_{D_N}\left[\frac{\sum_{i=1}^{N}(y_i - x_i^T \hat{\beta})^2}{N}\right] = \frac{N-p}{N}\sigma_w^2$.
This is the expected error on the training data itself.
The true Mean Integrated Squared Error (MISE), for predictions on new, independent data, in the case of a correct linear model, is:
$MISE = E_{D_N, y_{new}}\left[\frac{\sum_{i=1}^{N}(y_{new,i} - x_i^T \hat{\beta})^2}{N}\right] = \frac{N+p}{N}\sigma_w^2$.
Note that $E_{D_N}[\hat{MISE}_{emp}] \neq MISE$. Specifically, the empirical error underestimates the true generalization error.
An unbiased estimator of MISE can be formed by correcting the empirical error:
$\text{Unbiased MISE estimator} = \hat{MISE}_{emp} + 2\frac{p}{N}\sigma_w^2$.
However, this requires an estimate of the noise variance $\sigma_w^2$.

---
### 15. Criteria for Estimating Generalization Error: PSE and FPE
Using the unbiased estimate of noise variance $\hat{\sigma}_w^2 = \frac{SSE_{emp}}{N-p}$, we get practical criteria:
* **Predicted Squared Error (PSE)**:
    $PSE = \hat{MISE}_{emp} + 2\hat{\sigma}_w^2 \frac{p}{N}$.
* **Final Prediction Error (FPE)**:
    $FPE = \frac{1+p/N}{1-p/N} \hat{MISE}_{emp}$.
These criteria can be used for model selection, for example, in polynomial regression to choose the optimal degree $n$:
$\tilde{n} = \text{arg min}_n \left[ \hat{MISE}_{emp}(n) + 2\hat{\sigma}_w^2 \frac{n+1}{N} \right]$. (Note: $p=n+1$ for polynomial of degree $n$).
